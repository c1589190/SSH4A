# File Transfer

## Purpose

让 Agent 和脚本通过与远程命令相同的目标、认证参数及主机信任配置来上传和下载文件，并能判断传输有没有完成。

## ADDED Requirements

### Requirement: 使用连接配置传输文件

系统 SHALL 通过 SFTP 支持单个文件的上传和下载。两种操作 SHALL 接受与远程命令一样的连接配置及字段引用，并校验实际目标的主机密钥。

#### Scenario: 用跨配置字段传输文件

- **WHEN** 调用方使用配置 A 的主机和用户名及配置 B 的密码，上传一个本地二进制文件，再下载它
- **THEN** 下载后的文件字节与源文件完全一致

#### Scenario: 服务器没有可用的 SFTP 子系统

- **WHEN** SSH 登录成功但服务器不提供可用的 SFTP 子系统
- **THEN** 传输操作报错，退出状态表明失败

### Requirement: 稳定的目标文件覆盖和失败行为

系统 SHALL 默认只在最终路径空闲时发布传输结果。显式允许覆盖时 SHALL 在完整传输后替换已有文件；目标服务器无法提供所需替换操作时 SHALL 报错并保留原文件。

#### Scenario: 目标文件已存在

- **WHEN** 调用方试图写入已存在的目标路径且未启用覆盖
- **THEN** 系统报告冲突，目标文件内容保持完整

#### Scenario: 传输中途断开

- **WHEN** 本地写入失败或 SFTP 在完整文件发布前断开
- **THEN** 操作返回失败，最终路径仍为空或仍保留已有文件
- **AND** 系统尝试清理临时文件，并在无法确认清理时标明其路径
